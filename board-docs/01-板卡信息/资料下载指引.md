## 三、A 盘里最该先拿的四个文件

| 文件 | 为什么重要 |
|---|---|
| **《STM32F407 探索者开发指南》**（PDF/CHM） | 全部例程的讲解，第 25 章是 TFT-LCD 实验 |
| **例程源码（含 `lcd.c`）** | **完整的 NT35310 初始化序列就在这里**，本资料包的驱动只实现了显示纯色所需的最小集合 |
| **`EXPLORER_V3.4.pdf`**（主原理图） | 全板连接关系，含 BOOT 电路、CAN、以太网、音频 |
| **`探索者V3 IO引脚分配表.xlsx`** | 全部 IO 分配，核对引脚最快 |

其他有用文件：

- `ATK-MD0350 V2.4.pdf` —— 3.5 寸屏原理图（**本资料包已下载并解析**）
- `探索者V3 硬件参考手册_V1.0.pdf` —— 硬件变更说明（V3 vs V2：以太网 YT8512C、音频 ES8388、CAN 收发器 SIT1050）

## 五、本资料包已下载的文件

| 文件 | 大小 | SHA256 前 16 位 | 来源 |
|---|---|---|---|
| `02-原理图/ATK-MD0350_屏幕原理图_V2.4.pdf` | 346681 B | 见下方校验 | GitHub 公开镜像 |

校验命令：

```powershell
Get-FileHash "02-原理图/ATK-MD0350_屏幕原理图_V2.4.pdf" -Algorithm SHA256
```

> 该 PDF 已用文本流解析验证：确认 40 pin FPC 接口（`CS/RS/WR/RD/RST` + `DB0~DB15`）、背光 `LEDK1~6` + `LEDA` + `BL_CTR`、电阻触摸 `XP/Y-/X-/Y+`。**但原理图不含驱动 IC 型号**——那是屏幕模组内部的事，只能靠读 ID 确认。

## 六、网络受限时的应对

2026-11-03 实测：`raw.githubusercontent.com` 的 DNS 解析失败，百度网盘接口返回 `errno=-20`。

可行的替代路径：

1. **让官网资料页在浏览器里打开**，手动点网盘链接（浏览器走系统代理，一般能通）；
2. **用手机热点**给电脑联网后重试；
3. 直接问卖家要资料盘地址（购买记录里有店铺）。

已下载的 `ATK-MD0350 V2.4.pdf` 不受影响，本资料包内可直接查看。
