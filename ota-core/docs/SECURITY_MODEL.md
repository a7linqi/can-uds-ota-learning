# 安全模型：每一层挡什么、挡不住什么

本文件回答一个问题：**这套 OTA 到底防住了谁？** 不把"验证过的东西"和"想要的效果"混在一起。

## 1. 信任链

```
硬件读保护（RDP）        ← 唯一的信任根：没有它，下面每一层都能被改写
   └─ Bootloader（固定 0x08000000，不验自己）
        └─ 升级包 Ed25519 签名（公钥硬编码在 Bootloader 里）
             └─ App 区尾部 96 B 凭证（32 B 头 + 64 B 签名，擦除即失效）
                  └─ 元数据双副本 + CRC32 + 序号（EEPROM）
                       └─ TRIAL 试启动 + 回滚
```

关键设计：**凭证放在 App 区末尾**。安装时的擦除同时带走旧镜像和旧凭证，
所以不可能出现"旧凭证配新镜像"；备份恢复是把凭证**重放**，不是重新制造。

## 2. 威胁模型

| 攻击者能力 | 挡不挡得住 | 靠什么 | 实测证据 |
|---|---|---|---|
| 总线侧发送未签名包 | **挡** | `0x37` 验签失败 → NRC `0x72` | `SECURE_BOOT_EVIDENCE.md` |
| 改写镜像并重算所有 CRC | **挡** | 签名覆盖 32 B 头 + payload | 同上（伪造镜像被拒：`ticket signature does not verify`） |
| 直接换掉 App（SWD/拆焊） | **挡** | 无凭证 → `installed app has no signed ticket` | 同上 |
| 拔电中断升级（下载中） | **挡**（保旧固件） | DOWNLOADING 半事务 + 验签跳回 | `POWER_CUT_EVIDENCE.md` 实验二 |
| 拔电中断安装 | **挡**（自己装完） | READY/INSTALLING 幂等重做 | 同上 实验四 |
| App 装好了但起不来 | **挡**（回滚） | TRIAL 计数 + RESTORING | 同上 实验三 / `WATCHDOG_EVIDENCE.md` |
| App 卡死（软件死循环） | **挡**（看门狗） | IWDG 32.341 s | `WATCHDOG_EVIDENCE.md` |
| **通过 SWD 读固件** | **挡（RDP1）** | 读保护，`Data read failed` | `RDP_TRUST_ANCHOR_EVIDENCE.md` |
| **通过 SWD 改 Bootloader** | **挡（RDP1 挡写/擦）**，但**没开 WRP** | 生产应再开 WRP | 只验证了读保护 |
| **重放旧签名包 + 旧元数据（降级）** | **不挡** | 无单调版本计数器 | 明确未实现 |
| 电压毛刺 / 故障注入绕过校验 | **不挡** | — | 超出范围 |
| 拿到固件做逆向（RDP0 设备） | **不挡** | 需 RDP1 | 未上锁时 SWD 可完整读出 |

## 3. 实机数字（2026-11-05）

| 项 | 值 |
|---|---|
| RDP0 下 SWD 读 1 KiB | 成功，sha256 `7b1e4f0c…` |
| RDP1 下同一读 | `Error: Data read failed`，不产出文件 |
| RDP1 下运行 | 正常启动、UDS 应答、`IDLE/app/v20/seq 246` |
| 解锁（`-rdu`） | 16.265 s，RDP→`0xAA`，Flash 全 `0xFF` |
| 恢复后 | `IDLE/app/v23/45304 B/seq 253`，内部逐字节 == 构建产物 |

## 4. 已知缺口（不要写成"已解决"）

1. **降级重放**：版本策略只拦 `version <= active_version` 的常规包；能把元数据整体
   回滚的攻击者可以重放旧包。真正的单调计数器需要 OTP/安全芯片。
2. **Bootloader 自身无签名**：靠 RDP + WRP 保护，不靠自校验。
3. **演示密钥**：仓库里的 Ed25519 种子与公钥是演示用的，量产必须换密钥并保护私钥。
4. **无 WRP**：本轮没有对 Bootloader 扇区开写保护。
5. **无故障注入防护**：没有电压/时钟毛刺检测。
