## 一、五类岗位与 JD 原文关键词

| 岗位类别 | 代表公司 | JD 原文关键词 | 学历门槛 |
|---|---|---|---|
| 汽车电子 MCU 开发 | 德赛西威、经纬恒润、华阳 | 精通 MCU 嵌入式开发；I2C/UART/SPI；**Bootloader 升级**；ADC/GPIO；看懂原理图；CAN/AUTOSAR/功能安全"者优先" | 本科及以上（硕士优先） |

| 工控 / 通用嵌入式 | 汇川、信捷、雷赛 | C/C++；RTOS；单片机/ARM；SPI/I2C/UART；数据结构与算法；项目/竞赛经历优先 | 本科及以上 |

## 二、把 JD 拆成"硬门槛"和"加分项"

这是最容易被误读的地方。校招 JD 里大量条款写着"优先""者优先""了解即可"，那不是门槛，是排序权重。

### 硬门槛（几乎每份都有，缺了会被卡）

| 要求 | 出现位置 | 你的状态 |
|---|---|---|
| 熟练掌握 C 语言 | 全部 | ✅ 有（裸机 C99，无 libc 依赖） |
| MCU 外设：GPIO/ADC/UART/I2C/SPI | 全部 | ✅ 有（STM32F1/F4 全套） |
| 至少一个完整项目 | 全部 | ✅ 有（三个，其中两个实机闭环） |
| 能独立看懂硬件原理图 | 德赛西威明写 | ⚠️ **弱，需补** |
| 会用示波器/逻辑分析仪 | 比亚迪明写 | ⚠️ **弱，需补** |
| Bootloader 升级 | 德赛西威写在要求第 3 条 | ✅ **强项，直接命中** |

### 加分项（写了"优先"，没有不致命，有则排序靠前）

| 要求 | JD 原文 | 你的状态 |
|---|---|---|
| CAN 总线 | "了解 CAN 总线…者优先" | 🔶 在建（模型完成，实机未做） |
| AUTOSAR | "了解 AUTOSAR…者优先"；经纬恒润是"你将采用 AUTOSAR 开发"——**是入职后的事** | ❌ 无概念 |
| 功能安全 ISO 26262 / ASPICE | "了解…者优先" | 🔶 实习接触（TESSY 覆盖率），但没系统概念 |
| RTOS | 汇川"RTOS 优先" | ✅ 有（FreeRTOS 五个任务） |
| 竞赛 / 开源经历 | 经纬恒润"积极参加编程电子大赛者优先" | ❌ 无 |
| LIN / 车载以太网 | 经纬恒润"熟悉车辆总线网络（CAN、LIN、ETH）优先" | 🔶 实习在做 LIN 相关 |

**关键判断**：AUTOSAR 在校招 JD 里**几乎从不作为硬性门槛**，它是"你来了会用"，不是"你必须会"。所以它只值得花 3-5 天建立概念，不值得花两个月。

## 四、补齐清单（按投入产出排序）

### P0｜12 月前必须完成：CAN/UDS 实机闭环

- 为什么：这是你从"消费电子"跨到"车载"的唯一硬证据，也是唯一能证明"你做过车载协议栈"的东西
- 怎么做：USB-CAN 到货 → gs_usb 驱动 → python-can 设 500k/85.7% → 自写 ISO-TP → 跑通 0x10/0x22/0x34/0x36/0x37 → 一次 V1→V2 升级
- 验收：`verification.json` 里出现实机记录 + 一段 30 秒录屏
- 耗时：2-3 周（不含排障）

### P1｜1 月：AUTOSAR 概念 + 诊断语义（共 5-7 天，别多花）

- AUTOSAR CP 分层能画出来：SWC → RTE → BSW（Com / Dcm / Dem / NvM / EcuM / Os）
- 能回答："你的 UDS 实现对应 Dcm 的哪一层？缺什么？"
- ISO 14229 的服务状态机：会话、安全访问、条件检查、`0x78`
- 验收：一页纸对照图，能在面试时手画
- 不要做：装 AUTOSAR 工具链、读完整 ISO 文档

### P2｜一直欠着但最便宜：原理图 + 仪器

- 这是 JD 里明写的硬门槛，而你现在简历上**零证据**
- 成本极低，收益很高：
  - 拿探索者板的原理图，找出 CAN 收发器、终端电阻、BOOT0 电路，各画一遍信号路径
  - 用示波器抓一次 CAN_H/CAN_L 差分波形，截图存证（USB-CAN 调试时顺手做）
  - 用逻辑分析仪抓一次 SPI 读写 NOR 的时序
- 验收：面试能说"我量过这条总线的终端电阻是 60Ω"、"我看过这段 SPI 时序的 CS/CLK 相位"
- 耗时：一个周末

### P3｜明确不补

- CAN FD、车载以太网、AUTOSAR 工具链实操、嵌入式 Linux、深度学习
- 理由：四个月内做不出可信产出，且会挤占 P0

## 六、一句话结论

**你的硬门槛命中率是 4/6，缺的两项（原理图、仪器）成本只有一两天。**
真正的问题不是"能力不够"，而是"最强的那一项（Bootloader/OTA）在简历上还没被实机验证过"。
把 P0 做完，你在这个 JD 池子里的匹配度会从"能投"变成"值得面试"。
